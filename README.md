# Sistema de Administración de Citas

## Instalación y configuración

Este proyecto fue desarrollado en Java utilizando IntelliJ IDEA.

## Uso del programa

El sistema permite administrar doctores, pacientes y citas médicas.

## Tecnologías utilizadas

- Java 11
- IntelliJ IDEA
- Git
- GitHub
